# Backlog: the IDEAS.md format and the backlog prompt

The orchestrator skill's **Backlog** says when to record an idea. Each idea in `.work/orchestrator/IDEAS.md` is one
block:

```
## <the idea in one line>
- origin: <who or which chat>, <YYYY-MM-DD>
- value: <for the user>
- cost: <rough % of the week>
- reversible: yes | no
- status: open | started <YYYY-MM-DD> <thread> | done | dropped (<why>)
```

## On the watcher's backlog prompt

The prompt comes at the weekly reset, when usage is far behind pace, or when capacity is unused before a reset.

1. Start the most valuable reversible, in-budget open item the user would be proud to find started, through
   delegates. Set its status and report afterwards.
2. Empty backlog: mine the notes file and recent chats for forgotten ideas, add 3 grounded in the project's current
   state and start the best reversible one.
3. Irreversible or outward-facing items wait for the user.
